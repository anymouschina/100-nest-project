## 🎯 万能提示词模板生成器

### 核心模板（直接复制使用）

```
你是一位专业的提示词工程师。请基于以下需求，生成一个结构化的提示词模板：

## 需求描述
{用户具体需求}

## 生成要求
1. 使用变量占位符格式：{{变量名}}
2. 包含输入、处理、输出三个部分
3. 添加约束条件和边界情况
4. 提供示例填充
5. 给出使用说明

```markdown
### 模板名称
{{模板描述}}

#### 输入变量
- {{变量1}}: [描述]

#### 处理步骤
1. [步骤1]
2. [步骤2]

#### 输出格式
[输出格式说明]

#### 约束条件
- [约束1]
- [约束2]

#### 示例
输入：
- {{变量1}}: [示例值1]
- {{变量2}}: [示例值2]

输出：
[预期输出示例]
```
```

## 🎛️ 模板生成工具

### 快速模板生成器
```javascript
// 使用示例
const promptGenerator = {
  generate: (type, requirements) => {
    const baseTemplate = {
      role: "你是一位专业的{{领域}}专家",
      context: "背景：{{背景描述}}",
      task: "任务：{{具体任务}}",
      constraints: [
        "约束1：{{约束条件1}}",
        "约束2：{{约束条件2}}"
      ],
      output: "输出：{{输出要求}}",
      examples: "示例：{{示例内容}}"
    };
    
    return this.customizeTemplate(baseTemplate, type, requirements);
  }
};
```

### 模板验证器
```python
def validate_prompt_template(template: str) -> dict:
    """验证提示词模板的完整性"""
    required_fields = [
        "{{role}}", "{{task}}", "{{constraints}}", 
        "{{output}}", "{{examples}}"
    ]
    
    missing = [field for field in required_fields if field not in template]
    
    return {
        "is_valid": len(missing) == 0,
        "missing_fields": missing,
        "suggestions": generate_suggestions(missing)
    }
```

## 🚀 高级技巧

### 1. 动态变量注入
```
# 环境变量注入
{{ENV:API_KEY}}      # 从环境变量读取
{{DATE:YYYY-MM-DD}}  # 动态日期
{{RANDOM:uuid}}      # 生成随机ID
```

### 2. 条件逻辑模板
```
{% if {{复杂度}} == "高" %}
请提供详细的步骤分解和代码示例
{% else %}
请提供简洁的解决方案要点
{% endif %}
```

### 3. 链式模板
```
# 模板A输出作为模板B输入
模板A: {{需求}} -> 技术方案
模板B: {{技术方案}} -> 实现计划
模板C: {{实现计划}} -> 测试用例
```
